# Bouquet artwork

`botanical-sprites.webp` is original artwork generated for Dayflower on September 12, 2026, using OpenAI image generation. It does not contain artwork extracted from the reference websites.

The transparent 1536 × 1024 sprite sheet has four columns and two rows. Cells are 384 × 512 pixels. Row one: tulip, rose, daisy, sunflower. Row two: lavender, peony, ivory wrapping, lavender wrapping.

The editor and PNG export use these same sprite cells. Keep the ordering and dimensions stable: previously shared gift links refer to flower and wrapping indexes.
